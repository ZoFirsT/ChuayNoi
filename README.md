# ChuayNoi (ช่วยหน่อย)

บอร์ดให้นักศึกษาโพสต์ขอให้เพื่อนช่วยงานสั้น ๆ มีระบบ **แต้มน้ำใจ** ด้วย ตอนโพสต์ระบบจะกันแต้มไว้ก่อน แล้วค่อยจ่ายตอนงานผ่าน
ตัวโปรแกรมเป็น Python console app ทำส่งโปรเจกต์วิชา CS102 Fundamental of Computer Programming เทอม 1/2569

> ตอนนี้โครงโปรแกรมพร้อมแล้ว แต่ทุก function ยังเป็น `TODO` อยู่ รอแต่ละชุดงานมาเขียน

## วิธีรัน

ใช้ Python 3.10 ขึ้นไป ไม่ต้องลง library อะไรเพิ่ม

```bash
python tools/reset_data.py
```

```bash
python main.py
```

คำสั่งแรกจะสร้าง folder `data/` จาก sample data ให้ รันตอนใช้ครั้งแรก และทุกครั้งที่อยากเริ่ม test ใหม่ ใครใช้ macOS ให้พิมพ์ `python3` แทน

## โครงสร้าง folder

```text
main.py              จุดเริ่มโปรแกรม
chuaynoi/
├── app.py           เมนูหลัก
├── config.py        ค่าคงที่และกติกา
├── core/            คลาสข้อมูล อ่าน/เขียนไฟล์
├── ui/              รับข้อมูลและแสดงผล
├── accounts/        สมัคร / เข้าสู่ระบบ
├── wallet/          แต้มน้ำใจ
├── board/           ประกาศและการช่วยงาน
└── reports/         สถิติและส่งออก .txt
sample_data/         ข้อมูลตัวอย่าง
tools/reset_data.py  รีเซ็ตข้อมูลสำหรับทดสอบ
docs/                เอกสารของทีม
```
