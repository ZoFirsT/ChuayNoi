# บันทึกการใช้ AI

โจทย์ข้อ 6 บังคับให้จดทุกครั้งที่ใช้ AI และ file นี้จะเอาไปเป็นภาคผนวกของรายงานด้วย
**ใช้เสร็จให้จดทันที** อย่ารอมาเขียนย้อนหลัง

## กติกา

1. ใช้ AI ช่วยได้ตอนวิเคราะห์โจทย์ ออกแบบ เสนอแนวทางเขียนโค้ด อธิบาย error สร้าง test case และตรวจทานรายงาน
2. โค้ดที่ส่ง **ต้องอธิบายเองได้ทุกบรรทัด** ถ้าอธิบายไม่ได้ก็อย่าส่ง
3. ผล test กับภาพหน้าจอต้องมาจากการ run จริงเท่านั้น
4. ถ้าเอาโค้ดหรือข้อมูลมาจากที่อื่น (เว็บ, เอกสาร Python) ให้จดที่มาไว้ในช่อง "สรุปที่นำมาใช้"

## เพิ่มรายการยังไง

copy block ข้างล่างไปต่อท้าย file แล้วกรอกให้ครบทุกช่อง

```markdown
### #เลขลำดับ: หัวข้อสั้น ๆ

| ช่อง | รายละเอียด |
| --- | --- |
| วันที่ | |
| ผู้ใช้ | แกนกลาง / ชุด A / ชุด B |
| เครื่องมือ | ชื่อและรุ่น เช่น Claude, ChatGPT, Gemini |
| วัตถุประสงค์ | ใช้ทำอะไร |
| ตัวอย่าง Prompt | คัดคำถามจริงมา 1–2 ประโยค |
| สรุปที่นำมาใช้ | ใช้ส่วนไหน ไม่ใช้ส่วนไหน |
| วิธีตรวจสอบ | รันทดสอบอะไร เทียบกับอะไร ใครตรวจ |
```

| ผู้ใช้ | แกนกลาง |
| เครื่องมือ | Claude (Claude Code) |

### #4: ให้ AI ช่วย commit, push และเปิด PR ของงานแกนกลาง

| ช่อง | รายละเอียด |
| --- | --- |
| วันที่ | 18 พ.ย. 2569 |
| ผู้ใช้ | แกนกลาง |
| เครื่องมือ | Claude (Claude Code) |
| วัตถุประสงค์ | พอเขียนโค้ดเสร็จและ test ผ่านแล้ว ให้ AI เช็กทั้งไฟล์อีกรอบ แล้วรันคำสั่ง git ให้ คือ commit, push, เปิด PR และสร้าง branch ใหม่จาก `main` ล่าสุดหลัง merge ทำไป 5 รอบ ได้ `feat: models` (#19), `feat: storage` (#20), `feat: wallet` (#21), `feat: display` (#22), `feat: wallet menu` (#23) |
| ตัวอย่าง Prompt | "commit pr เลย" และ "Merge แล้ว ไปต่อ storage" |
| สรุปที่นำมาใช้ | ใช้คำสั่ง git/gh ที่ AI รันให้ ข้อความ commit `feat: ...` กับคำอธิบาย PR ที่ AI ร่างจากผล test (ติ๊ก checklist ให้ 3 ข้อที่เช็กได้จากเครื่อง ส่วนข้อ "อธิบายโค้ดได้เอง" กับข้อ ai-log ติ๊กเอง) AI ไม่ได้แก้โค้ดในไฟล์ ยกเว้นลบบรรทัด comment โค้ดเก่า 1 บรรทัดใน `change_status` ก่อน commit models (ไม่เปลี่ยน logic) ส่วนการ merge กด Squash and merge เองบน GitHub รายการ ai-log นี้ AI ร่างให้ แล้วแก้ช่องวิธีตรวจสอบให้ตรงกับที่ทำจริง |
| วิธีตรวจสอบ | รัน test ของแต่ละขั้นใน python3 ตามที่ AI ให้ไว้ แล้วให้ AI รันซ้ำทั้งไฟล์ ผ่าน C1, C2, C3, C4, C5, C6, C8, C9, C10, C11, C12 บางขั้น (S5, W2, W3, D1) AI เจอชื่อค่าใน config หรือชื่อ function สะกดผิดตอนเช็ก เลยแก้เองแล้วให้เช็กใหม่จนผ่าน ช่วง display ให้ AI รัน test ใน Terminal ของแอป Claude ให้ดูไปพร้อมกัน ก่อนกด merge เปิดแท็บ Files changed ดูว่าแก้แค่ไฟล์ที่ตั้งใจและตรงกับที่เขียนเอง |
