# บันทึกการใช้ AI

โจทย์ข้อ 6 บังคับให้จดทุกครั้งที่ใช้ AI และ file นี้จะเอาไปเป็นภาคผนวกของรายงานด้วย
**ใช้เสร็จให้จดทันที** อย่ารอมาเขียนย้อนหลัง

## กติกา

1. ใช้ AI ช่วยได้ตอนวิเคราะห์โจทย์ ออกแบบ เสนอแนวทางเขียนโค้ด อธิบาย error สร้าง test case และตรวจทานรายงาน
2. โค้ดที่ส่ง **ต้องอธิบายเองได้ทุกบรรทัด** ถ้าอธิบายไม่ได้ก็อย่าส่ง
3. ผล test กับภาพหน้าจอต้องมาจากการ run จริงเท่านั้น
4. ถ้าเอาโค้ดหรือข้อมูลมาจากที่อื่น (เว็บ, เอกสาร Python) ให้จดที่มาไว้ในช่อง "สรุปที่นำมาใช้"

## เพิ่มรายการยังไง

copy block ข้างล่างไปต่อท้าย file แล้วกรอกให้ครบทุกช่อง

```markdown
### #เลขลำดับ: หัวข้อสั้น ๆ

| ช่อง | รายละเอียด |
| --- | --- |
| วันที่ | |
| ผู้ใช้ | แกนกลาง / ชุด A / ชุด B |
| เครื่องมือ | ชื่อและรุ่น เช่น Claude, ChatGPT, Gemini |
| วัตถุประสงค์ | ใช้ทำอะไร |
| ตัวอย่าง Prompt | คัดคำถามจริงมา 1–2 ประโยค |
| สรุปที่นำมาใช้ | ใช้ส่วนไหน ไม่ใช้ส่วนไหน |
| วิธีตรวจสอบ | รันทดสอบอะไร เทียบกับอะไร ใครตรวจ |
```

## รายการ

### #1: วิเคราะห์โจทย์และเปลี่ยนแผนจากเว็บเป็น Console

| ช่อง | รายละเอียด |
| --- | --- |
| วันที่ | 17 พ.ย. 2569 |
| ผู้ใช้ | แกนกลาง |
| เครื่องมือ | Claude (Claude Code) |
| วัตถุประสงค์ | เอาเอกสารโจทย์ CS102 มาเทียบกับแผนเดิมที่เป็นเว็บแอป แล้วออกแบบแผนใหม่ให้เป็น Python Console Application |
| ตัวอย่าง Prompt | "ช่วยออกแบบเปลี่ยนแผนให้หน่อย ให้เข้ากับโปรเจควิชานี้ตามเอกสารที่อาจารย์ส่งมาให้" และ "ไม่ต้องทำเป็นเว็บ ทำเป็น application console อย่างเดียว" |
| สรุปที่นำมาใช้ | เอาขอบเขต feature กติกาแต้ม สถานะงาน และการแบ่งงานมาใช้ (อยู่ใน `docs/01-overview.md` กับ `docs/02-design.md`) |
| วิธีตรวจสอบ | _(ทีมกรอก)_ เช็กแผนเทียบกับโจทย์ข้อ 4–9 ทีละข้อตอนประชุมกลุ่ม |

### #2: จัดโครงสร้าง repo เป็น module และเขียน doc แบ่งชุดงาน

| ช่อง | รายละเอียด |
| --- | --- |
| วันที่ | 17 พ.ย. 2569 |
| ผู้ใช้ | แกนกลาง |
| เครื่องมือ | Claude (Claude Code) |
| วัตถุประสงค์ | จัดโค้ดเป็น package แยกตาม feature เขียน doc ให้เพื่อน ๆ เลือกชุดงาน และตั้งค่า GitHub (Issue, Label, Milestone, ฟอร์ม PR) |
| ตัวอย่าง Prompt | "จัด code structure ไว้สำหรับเขียนเป็น module … เขียนเพื่อให้เพื่อนในกลุ่มไปเลือก" |
| สรุปที่นำมาใช้ | โครง file ทุก file ใน `chuaynoi/` ซึ่งมีแค่ชื่อ function กับคำอธิบายสั้น ๆ **ยังไม่มีตัวโค้ด** ส่วนที่ AI เขียนเป็นโค้ดจริงมี 3 จุด คือค่าคงที่ใน `chuaynoi/config.py`, `main.py` (3 บรรทัด) และ `tools/reset_data.py` (tool ไว้ reset data ไม่นับเป็นงานของชุดไหน) |
| วิธีตรวจสอบ | import ได้ทุก module ไม่มี error, `python tools/reset_data.py` copy ครบ 5 file, sample data มีแต้มรวม 400 = 100 × 4 คน - _(ทีมกรอกเพิ่ม)_ ทุกคนอ่าน `config.py` กับ `tools/reset_data.py` แล้วอธิบายได้ |
