# ส่งโปรเจกต์

สัปดาห์ 5 อ่านหน้านี้ก่อนเตรียมของส่ง เจ้าของ repo รวมของทุกส่วน คนอื่นส่งส่วนของตัวเองให้ครบตามหน้านี้ ส่วนวิธีส่ง code ขึ้น GitHub ดูใน `03-workflow.md`

## ของที่ต้องส่ง

| ส่งอะไร | ชื่อไฟล์หรือรูปแบบ |
| --- | --- |
| code กับไฟล์ข้อมูล | `CS102_Sec[XX]_Group[YY].zip` |
| รายงาน PDF | `Report_CS102_Sec[XX]_Group[YY].pdf` |
| คลิป 5–7 นาที | ลิงก์ YouTube (Unlisted) หรือ Google Drive |

- วันส่งโปรเจกต์คือ 29 พ.ย. 2569
- เลข section และเลข group ใน `[XX]` กับ `[YY]` (รอยืนยัน)
- งานของทีมทั้งหมดไล่ใน Issue #9 ส่งโปรเจกต์ทาง Google Form

## ZIP

เจ้าของ repo เป็นคนแพ็ก

1. run `python tools/reset_data.py` ก่อน
2. แพ็กเฉพาะ `main.py`, `chuaynoi/` และ `data/`
3. เช็กว่าใน ZIP ไม่มี `__pycache__`
4. แตก ZIP บนเครื่องอื่น ควรเป็น Windows แล้ว run `python main.py` ต้องเข้าหน้าแรกได้

## รายงาน PDF

แต่ละคนเขียนส่วนของชุดตัวเอง แล้วเจ้าของ repo รวมเป็น PDF ฉบับเดียว AI ช่วยวางโครง ร่างเนื้อหา และตรวจภาษาได้ แต่เจ้าของส่วนต้องอ่านแก้ให้เป็นคำของตัวเอง อธิบายได้ทุกย่อหน้า และจดลง `docs/ai-log.md` ว่าส่วนไหน AI ร่าง ภาพหน้าจอกับผล test ต้องมาจากการ run จริง

| ส่วน | ใครเขียน | ต้องมีอะไร |
| --- | --- | --- |
| การออกแบบ | เจ้าของ repo | กติกาแต้ม status ไฟล์ข้อมูล และ flowchart ภาพรวมโปรแกรม |
| แกนกลาง | เจ้าของ repo | คำอธิบาย function ของแกนกลาง คู่มือเมนูหลักกับกระเป๋าแต้ม และผล C1–C14 |
| ชุด A | คนที่เลือกชุด A | flowchart ของ `create_request` กับ `approve_work` คำอธิบาย function ทั้ง 6 ตัว (ชื่อ รับอะไร คืนอะไร ทำอะไร) คู่มือเมนู 1–4 พร้อมภาพหน้าจอจริง และผล A1–A16 |
| ชุด B | คนที่เลือกชุด B | คำอธิบาย function ทั้ง 6 ตัว คู่มือหน้าจอสมัคร เข้าสู่ระบบ และสถิติ พร้อมภาพหน้าจอจริง ตารางการจัดการ input ผิด (พิมพ์อะไรไปแล้วโปรแกรมตอบอะไรกลับมา) และผล B1–B13 |
| ภาคผนวก AI log | เจ้าของ repo รวม | เนื้อหาจาก `docs/ai-log.md` ของทุกคน |

- งานรวมเล่ม ตรวจว่าครบทุกส่วน และ export เป็น PDF เป็นของเจ้าของ repo
- จำนวนหน้า รูปแบบตัวอักษร และน้ำหนักคะแนนของรายงาน (รอยืนยัน)

## คลิป

ความยาวรวม 5–7 นาที ทุกคน demo ส่วนของตัวเองและอธิบาย code ที่ตัวเองเขียน

| ชุด | ต้องโชว์อะไร |
| --- | --- |
| ชุด A | โพสต์ สมัครช่วย ส่งผลงาน แล้วยืนยันงาน ให้เห็นว่าแต้มโอนจริง โชว์กรณีแต้มไม่พอด้วย แล้วเปิด code `create_request` อธิบาย |
| ชุด B | พิมพ์ผิดหลายแบบแล้วโปรแกรมไม่พัง สมัครผู้ใช้ใหม่ เปิดไฟล์รายงาน `.txt` ที่ export แล้วเปิด code `input_int` อธิบาย |
| แกนกลาง | อธิบายโครงสร้างโปรแกรมกับระบบแต้ม แล้วเปิด code `get_balance` หรือ `add_transaction` อธิบาย |

หลัง upload ตั้งให้ใครมีลิงก์ก็ดูได้ แล้วลองเปิดลิงก์ในหน้าต่าง incognito
