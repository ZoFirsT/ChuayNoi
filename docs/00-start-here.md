# 00: เริ่มตรงนี้ก่อน

เพิ่งเข้าทีมมาใช่มั้ย อ่านหน้านี้หน้าเดียวก่อนก็พอ จบแล้วจะรู้ว่าต้องทำอะไรต่อ ส่วนรายละเอียดลึก ๆ ค่อยตามลิงก์ไปอ่านทีหลัง

## โปรเจกต์นี้คืออะไร

ChuayNoi (ช่วยหน่อย) เป็น Python console app ของวิชา CS102 เป็นบอร์ดให้เพื่อนโพสต์ขอให้ช่วยงานสั้น ๆ แล้วจ่ายกันด้วยแต้มน้ำใจ เขียนด้วย Python ล้วน ไม่ต้องลง library อะไรเพิ่ม

อยากเห็นภาพรวมเต็ม ๆ อ่าน [01-overview.md](01-overview.md)

## งานแบ่งยังไง

มี 3 ชุด แกนกลางเราทำเอง อีก 2 ชุดให้ทุกคนเลือกกันคนละชุด

| ชุด | ทำอะไร | ขนาดงาน |
| --- | --- | --- |
| แกนกลาง | class, อ่าน/เขียนไฟล์, ระบบแต้ม, main menu | 7 function + 5 class |
| ชุด A บอร์ดประกาศ ★★★ | โพสต์ ค้นหา รับช่วย ส่งงาน ยืนยันงาน ปิดรับ | 6 function + 4 หน้าจอ |
| ชุด B ผู้ใช้ input และรายงาน ★★ | รับ input สมัคร/login สถิติ export รายงาน | 6 function + 3 หน้าจอ |

ได้ชุดไหนไปก็รับผิดชอบชุดนั้นทั้งหมด ทั้ง code, test, ส่วนของตัวเองในรายงาน และคลิป

ชุด B เริ่มได้เลยไม่ต้องรอใคร ส่วนชุด A ต้องรอแกนกลางเสร็จก่อน ระหว่างรอก็อ่าน doc แล้วร่าง flowchart ไปก่อนได้ อยากเทียบสองชุดแบบละเอียดดูใน [tasks/README.md](tasks/README.md)

## ทำตอนนี้เลย

1. ส่ง username GitHub มาในกลุ่ม เดี๋ยวเราเชิญเข้า repo ให้ แล้วอย่าลืมไปกด Accept ใน email ด้วย
2. ลง Python 3.10 ขึ้นไป, VS Code และ GitHub Desktop ใครใช้ Windows ตอนลง Python ติ๊ก **Add python.exe to PATH** ด้วยนะ
3. clone repo ผ่าน GitHub Desktop แล้วลอง run สองคำสั่งนี้

   ```bash
   python tools/reset_data.py
   python main.py
   ```

   ใครใช้ Mac พิมพ์ `python3` แทน ถ้าขึ้น `NotImplementedError: TODO(แกนกลาง): run` ไม่ต้องตกใจ แค่ยังไม่มีใครเขียน code เท่านั้นเอง step ละเอียดอยู่ใน [03-workflow.md](03-workflow.md)
4. อ่าน [tasks/README.md](tasks/README.md) แล้วเลือกว่าจะเอาชุด A หรือ B
5. ไปแท็บ Issues เปิด [#14 ชุด A](https://github.com/ZoFirsT/ChuayNoi/issues/14) หรือ [#15 ชุด B](https://github.com/ZoFirsT/ChuayNoi/issues/15) กด Assignees ทางขวาแล้วเลือก assign yourself จากนั้น comment ว่า "เลือกชุดนี้"

ถ้าสองคนอยากได้ชุดเดียวกัน คุยกันในกลุ่มก่อน ขอให้ตัดสินให้จบภายใน **20 พ.ย. 2569**

## ทำงานร่วมกันยังไง

- push เข้า `main` ตรง ๆ ไม่ได้ (ตั้งกันไว้แล้ว) ให้ทำใน branch ของตัวเองแล้วเปิด PR
- ทำทีละ function หรือทีละหน้าจอ เสร็จชิ้นไหนเปิด PR ชิ้นนั้น เพื่อนจะได้ review ง่าย
- ชื่อ branch: ชุด A ใช้ `a/ชื่องาน` เช่น `a/create-request` ส่วนชุด B ใช้ `b/ชื่องาน` เช่น `b/input-int`
- commit ขึ้นต้นด้วย `feat:` / `fix:` / `docs:` เช่น `feat: input_int`
- เปิด PR แล้วใส่เพื่อนอีกคนเป็น Reviewer ต้องมีคน approve 1 คนถึงจะ merge ได้ แล้วกด Squash and merge
- ก่อน test ทุกรอบ run `python tools/reset_data.py` ก่อน ผลจะได้ตรงกับ test case ใน doc
- ใช้ AI ได้ แต่ต้องอธิบาย code ของตัวเองได้ทุกบรรทัด (อาจารย์ถามแน่) และจดลง [ai-log.md](ai-log.md) ทุกครั้งที่ใช้

ที่เหลือละเอียดอยู่ใน [03-workflow.md](03-workflow.md)
