folder นี้มีคู่มือ 3 ไฟล์ เขียนไว้ให้ AI ที่เราใช้อ่าน มันจะได้รู้ว่าโปรเจกต์นี้คืออะไร เราทำชุดไหน ตอนนี้ถึงไหนแล้ว และต้องทำอะไรต่อ ใช้ได้ตั้งแต่วันแรกจนถึงวันส่ง

| --- | --- |
| แกนกลาง | [core.md](core.md) |

## ใช้กับ ChatGPT หรือ Gemini บนเว็บ

1. เปิดไฟล์ของชุดตัวเองบน GitHub แล้วกดปุ่ม Copy raw file ที่มุมขวาบนของไฟล์
2. เปิดแชทใหม่ วางทั้งไฟล์เป็นข้อความแรก แล้วพิมพ์ต่อท้ายว่าวันนี้อยากทำอะไร
3. ถ้า AI ขอดู step ละเอียดของ function ให้ copy ไฟล์ใน `docs/tasks/` ของชุดตัวเองไปวางด้วย ถ้าขอดู code ก็ copy ไฟล์ที่กำลังเขียนไปให้

เริ่มงานชิ้นใหม่เมื่อไหร่ เปิดแชทใหม่แล้ววางคู่มือใหม่ทุกครั้ง AI จะได้ไม่สับสนกับเรื่องเก่า

## ใช้กับ AI ใน VS Code (Copilot, Cursor และตัวอื่น ๆ)

แทบไม่ต้องทำอะไร พวกนี้อ่าน [AGENTS.md](../../AGENTS.md) ที่ root ของ repo เองอยู่แล้ว แล้ว AGENTS.md จะชี้ต่อมาที่คู่มือของแต่ละชุด ถ้าตัวไหนไม่อ่านเอง ให้พิมพ์บอกมันว่า "อ่าน AGENTS.md กับ docs/ai/a-board.md ก่อน" (เปลี่ยนเป็นไฟล์ของชุดตัวเอง)

## ประโยคเริ่มคุยที่ใช้บ่อย

- "ช่วยดูหน่อยว่าตอนนี้เราถึงไหนแล้ว ต้องทำอะไรต่อ"
- "พาเขียน `input_int` ทีละ step หน่อย"

- "error นี้แปลว่าอะไร" แล้ว paste Traceback มาทั้งก้อน
- "ช่วยเช็กว่า test case ที่ run มาครบตาม doc ยัง" แล้ว paste ผลที่ run จริง

## กติกาที่ต้องจำ

AI ในคู่มือพวกนี้ตั้งไว้เป็นติวเตอร์ มันจะพาคิดและ review ให้ แต่จะไม่เขียน function ให้ทั้งตัว เพราะเราต้องอธิบาย code ของตัวเองได้ทุกบรรทัดตอนอาจารย์ถาม ใช้เสร็จแล้วจดลง [ai-log.md](../ai-log.md) ทุกครั้งนะ
